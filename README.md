# TOKYO BUCHIAGE Uploader — GitHub Pages package

This folder is a complete replacement for the published `tokyo-buchiage-legal` site.

## Publish

1. In the `fhibarin-coder/tokyo-buchiage-legal` repository, replace the existing published files with every file in this folder.
2. Keep all files at the repository root (not inside a nested `tokyo-buchiage-legal-site` folder).
3. Commit and push. GitHub Pages will publish `index.html` at `https://fhibarin-coder.github.io/tokyo-buchiage-legal/`.
4. Check the live homepage, Terms, Privacy, and Contact links on a phone and desktop browser before requesting TikTok review.

## Brand-icon consistency (required)

`brand-icon.png` is referenced by every page for both the visible brand icon and the browser favicon. Upload the **exact same `brand-icon.png` file** as the TikTok Developer Portal App icon. Do not substitute the old favicon or another icon.

If the portal needs a larger upload, resize this same source image without redesigning or replacing it; keep the resulting image visually identical. The website and favicon should continue to use `brand-icon.png`.

## Files

- `index.html` — full public information site
- `terms.html` / `privacy.html` — policy pages consistent with the personal-tool use case
- `contact.html` — official creator channel and safe contact guidance
- `styles.css` — responsive layout
- `brand-icon.png` — shared website/logo/favicon source

No login page or test account is included, because the site is informational and the tool is a personal creator utility.
